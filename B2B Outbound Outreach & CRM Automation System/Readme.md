
AI-Powered B2B Outbound Outreach & CRM Automation System

This repository contains an autonomous, multi-stage sales operations blueprint built for Make.com (formerly Integromat). The pipeline handles the complete outbound lifecycle: it tracks new target targets inside your CRM spreadsheet, instructs advanced LLM models via API to conduct granular organizational profiling, auto-drafts tailored copy variations, scans incoming mail channels for consumer feedback, and runs semantic classifications to determine buyer interest levels.

Workflow Architecture & Data Flow

The system runs on two unified automation routines managed inside a single workflow canvas:
[OUTBOUND PIPELINE]
[Watch Rows (Leads)] ──> [Groq LLM Research] ──> [Parse JSON] ──> [Update Row (Insights)] ──> [Groq LLM Email Draft] ──> [Parse JSON] ──> [Update Row (Copy)]

[INBOUND PIPELINE]
[Execute Email Search] ──> [Groq LLM Inbox Classifier] ──> [Parse JSON] ──> [Add Row (Replies Tab)]

📤 Phase 1: Outbound Research & Personalization

1. Watch Rows (Module ID: 1): Polls the Leads sheet inside the master CRM (Spreadsheet ID: 19-nDjhpBFc5f7HLJR-Kh3zduJ6-iuiLjNW7NvgiTAI8) for new prospects.
2. Groq Research Agent (Module ID: 7): Calls the Groq completions endpoint leveraging openai/gpt-oss-120b to evaluate structural customer metrics (Company, Website, Industry, Country, Contact Role) under low temperature (0.2) variables.
3. Parse JSON & CRM Sync (Module IDs: 9 & 8): Standardizes data variables and maps corporate summary data, key values, and pain points directly into columns K through P on the corresponding row entry.
4. Cold Email Draft Engine (Module ID: 10): Sends the processed insights back to the LLM platform to compile context-aware sales subject lines and body copy variants.
5. Parse JSON & CRM Copy Sync (Module IDs: 11 & 12): Saves finished, copy-pasteable communication blocks into columns Q and R.

📥 Phase 2: Inbound Response Intelligence

1. Execute Email Search Query (Module ID: 14): Continuously checks your connected INBOX folder for unread message bundles.
2. Groq Inbox Classifier (Module ID: 15): Analyzes inbound sender records, subjects, and text blocks to match them against structural semantic categories (INTERESTED, NOT_INTERESTED, QUESTION, MEETING_REQUEST, OUT_OF_OFFICE, UNSUBSCRIBE, OTHER).
3. Add Row to Replies (Module IDs: 16 & 17): Appends metadata insights, classification confidence scores, and suggested follow-up scripts into a dedicated tracking sheet (Replies tab) for manual audit review workflows.

Deployment & Verification Guide


1. Prerequisites

• An active Make.com account profile (registered or operating inside the ://make.com zone).
• Admin access permissions for your target AI LeadGen CRM spreadsheet.
• A valid Groq API Cloud Key with explicit model authorization access for openai/gpt-oss-120b.

2. Installation Steps

1. Download the blueprint file configuration text (Integration Google Sheets.json) directly to your workspace.
2. Create an empty project flow canvas in your Make control panel, click on the More icon (three horizontal dots ...) in the tool tray, and choose Import Blueprint.
3. Open the Watch Rows settings framework and choose your active account connection profile: aayush's Google connection.
4. Open the configuration panel for all three HTTP Request modules (IDs: 7, 10, 15) and find the Headers section. Update the value field for the Authorization header key to match this format exactly:text
Bearer YOUR_GROQ_API_KEY
Use code with caution.
5. Access the parameters window for the final Add Row block (Module ID: 17) to confirm it targets the correct Replies destination worksheet tab inside your spreadsheet file container.
6. Set your polling processing rules, switch the main system tracking control from OFF to ON, and run a sample row update to test the system.
